Chạy agent trên Linux từ số 0

Cần máy Linux có giao diện desktop, trình duyệt và Python 3.10 trở lên. Không cần pip, môi trường ảo, Node.js, Docker hoặc Internet khi chạy. File Chay.cmd chỉ dành cho Windows; trên Linux dùng lệnh dưới đây.

1. Giải nén và mở Terminal

  1. Dùng trình quản lý tệp giải nén Oantuti-Local.zip. Mở thư mục Oantuti-Local đã giải nén, nơi có my_agent.py và thư mục app. Không chạy bên trong file ZIP.
  2. Nhấp chuột phải vào khoảng trống trong thư mục, chọn Open in Terminal / Mở trong Terminal nếu có. Terminal là cửa sổ để nhập lệnh; gõ lệnh rồi nhấn Enter.
  3. Nếu không có mục đó, mở ứng dụng Terminal từ menu ứng dụng, gõ cd (có dấu cách), rồi kéo thư mục đã giải nén vào Terminal và nhấn Enter. Hoặc dùng đường dẫn đầy đủ đặt trong dấu nháy kép, ví dụ bên dưới.
cd "/home/ten-cua-ban/Downloads/Oantuti-Local"

Đây là ví dụ: thay đường dẫn bằng thư mục thực tế trên máy bạn. Dùng pwd để xem thư mục hiện tại và ls để kiểm tra có my_agent.py và app.

2. Kiểm tra Python rồi chạy bằng một lệnh

Kiểm tra phiên bản:

python3 --version

Nếu thấy Python 3.10.x hoặc mới hơn như 3.11, 3.12 thì dùng được. Nếu báo không tìm thấy lệnh hoặc phiên bản quá cũ, cài/nâng cấp Python qua trình quản lý phần mềm của bản Linux bạn dùng. Công cụ không tự cài hay thay đổi Python hệ thống.

Trong thư mục chứa my_agent.py, chạy:

bash app/Chay.sh

Không cần chạy chmod, không dùng sudo. Script tự tìm python3 hoặc python có phiên bản phù hợp. Trình duyệt sẽ tự mở, hãy giữ Terminal này mở trong lúc thử agent.

Nếu không tự mở trình duyệt, mở thủ công địa chỉ http://127.0.0.1:... in trong Terminal. Số phía sau dấu hai chấm thay đổi mỗi lần chạy; hãy dùng đúng địa chỉ mới in ra.

Muốn tự mở trình duyệt thay vì tự động:

bash app/Chay.sh --no-browser

Có thể chạy trực tiếp Python nếu không muốn dùng script:

python3 -B app/start.py

3. Chạy nguyên mẫu, rồi sửa agent

  1. Bấm Chạy thử với Greedy. Agent mẫu màu xanh đi trước; Greedy màu đỏ là đối thủ cố định.
  2. Mở my_agent.py bằng trình soạn thảo văn bản có sẵn trên Linux. Không đổi tên file hoặc sửa phần trong thư mục app.
  3. Lưu file bằng Ctrl+S, rồi bấm Chạy lại với Greedy. Công cụ đọc bản đã lưu ở đầu mỗi trận; thay đổi khi trận đang chạy chỉ dùng cho trận tiếp theo.

Để hiểu từng dòng code, tọa độ và bài tập ưu tiên ăn quân, mở hướng dẫn agent từ số 0 hoặc bấm Bắt đầu từ số 0 trong giao diện.

4. Xem live, tua và đọc lỗi

Mặc định bàn cờ theo nước mới nhất. Thanh tua, nút Trước/Sau và danh sách nước đi cho phép xem lại trong lúc agent vẫn chạy. Về hiện tại bật theo dõi trực tiếp. Tạm dừng xem chỉ dừng hình; Dừng trận mới dừng tính toán.

Khung đỏ chỉ file, dòng code, lượt xảy ra lỗi và gợi ý sửa. Có đoạn code tại thời điểm chạy, traceback, log và nút sao chép. Sửa đúng dòng, Ctrl+S rồi chạy lại.

Kết quả được lưu trong app/results/. Nút Tải replay HTML tạo file mở offline trong trình duyệt; không cần server còn chạy. Bản ghi không chứa toàn bộ mã nguồn agent nhưng có thể chứa log bạn in ra.

5. Dừng chương trình và xử lý sự cố

  • Thoát: bấm Thoát công cụ hoặc nhấn Ctrl+C trong Terminal. Đóng tab trình duyệt không dừng trận/server.
  • No such file or directory: Terminal đang ở sai thư mục. Dùng ls, rồi chuyển vào nơi chứa my_agent.py trước khi chạy lệnh.
  • Permission denied: gọi đúng bash app/Chay.sh, không gọi trực tiếp ./app/Chay.sh. Giải nén vào thư mục cá nhân có quyền ghi; không cần sudo.
  • Không tìm thấy Python 3.10 trở lên: kiểm tra phiên bản, cài/nâng cấp Python qua công cụ phần mềm của hệ điều hành.
  • Trình duyệt không mở: chép URL trong Terminal vào thanh địa chỉ. Công cụ chỉ mở trên máy bạn tại 127.0.0.1.
  • Mất kết nối: kiểm tra Terminal còn mở. Nếu đã thoát, chạy lại lệnh và mở URL mới.
  • Không khởi động được: đọc thông báo Terminal và file app/logs/startup.log nếu có. Giải nén đầy đủ bộ công cụ trước khi thử lại.

Đây là công cụ chạy code bạn tin cậy, không có sandbox. Luật giống đấu thường; giới hạn CPU/RAM và tốc độ không được bảo đảm giống máy chấm.
