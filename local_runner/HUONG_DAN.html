Tự viết agent đầu tiên

Bạn không cần biết làm website, cài server hay cài thư viện. Bộ này cho máy tính chạy code Python của bạn để đấu thử với một đối thủ Greedy cơ bản.

Dùng Linux? Mở hướng dẫn Linux từng bước. Trong thư mục đã giải nén, chạy bash app/run.sh; không cần chmod hoặc cài thư viện.

1. Mở công cụ lần đầu

  1. Giải nén ZIP ra một thư mục bình thường. Không chạy trực tiếp bên trong cửa sổ ZIP.
  2. Máy cần Python 3.10 trở lên. Nếu run.cmd báo thiếu Python, cài Python và bật Add Python to PATH, sau đó mở lại.
  3. Trong thư mục giải nén, nhấp đúp run.cmd. Trình duyệt sẽ mở giao diện. Giữ cửa sổ lệnh mở trong lúc sử dụng.
  4. Bấm Chạy thử với Greedy để chạy nguyên mẫu trước. Bạn là quân xanh P1, đi trước. Greedy là quân đỏ P2.

Nếu nhấp đúp không chạy: mở thư mục bằng File Explorer, gõ cmd trên thanh địa chỉ và Enter. Trong cửa sổ vừa mở, gõ run.cmd rồi Enter. Nếu trình duyệt không tự mở, sao chép địa chỉ http://127.0.0.1:... được in trong cửa sổ vào trình duyệt.

Trên macOS/Linux có thể mở terminal tại thư mục và chạy python3 -B app/start.py. File run.cmd dành riêng cho Windows.

2. Agent là gì?

Agent là hàm chọn nước đi. Mỗi lượt, engine gửi tình hình bàn cờ vào hàm agent(observation, configuration). Hàm trả về một nước; engine kiểm tra rồi thực hiện nước đó. Bạn không phải tự điều khiển giao diện.

Bạn chỉ sửa my_agent.py, nằm ngoài thư mục app. Không đổi tên file hoặc tên hàm. Toàn bộ phần còn lại đã có sẵn trong app.

Mở file bằng Python IDLE (nhấp phải → Edit with IDLE nếu có), Notepad hoặc trình soạn thảo code. Không dùng Word. Nhấn Ctrl+S sau mỗi lần sửa. Khi lưu bằng Notepad, chọn UTF-8 và bảo đảm tên là my_agent.py, không phải my_agent.py.txt. Có thể bật View → File name extensions trong File Explorer để kiểm tra.

Các dòng bắt đầu bằng # là chú thích để đọc. Python phân biệt thụt lề: dùng 4 dấu cách cho một cấp, không trộn tab và dấu cách.

3. Hiểu mẫu có sẵn

def agent(observation, configuration):
    moves = observation["valid_moves"]
    if not moves:
        return None

    chosen_move = moves[0]

    return {
        "from_col": chosen_move["from_col"],
        "from_row": chosen_move["from_row"],
        "to_col": chosen_move["to_col"],
        "to_row": chosen_move["to_row"],
    }

def định nghĩa hàm. observation là dữ liệu engine cung cấp. moves là danh sách nước hợp lệ. moves[0] chọn phần tử đầu tiên; Python đếm từ 0. return gửi nước đã chọn về engine. Nếu không có nước, mẫu trả None; None không phải bỏ lượt, máy chấm xử là không trả được nước đi.

Trường trả vềÝ nghĩa
from_col, from_rowCột và hàng của quân muốn đi.
to_col, to_rowCột và hàng của ô đích.

Cả bốn giá trị là số nguyên từ 0 đến 8. Cột a–i ứng với 0–8; hàng 1–9 ứng với 0–8. Ví dụ a1 = (0, 0), i9 = (8, 8). Hãy chọn từ valid_moves trước khi tự tính tọa độ.

4. Bài tập đầu tiên: ưu tiên ăn quân

Tìm dòng chosen_move = moves[0], thay đúng dòng đó bằng đoạn dưới. Giữ nguyên phần return. Đoạn mới chọn nước ăn quân đầu tiên; nếu không có, giữ nước đầu tiên.

    chosen_move = moves[0]
    for move in moves:
        if move["is_capture"]:
            chosen_move = move
            break

Lưu file rồi bấm Chạy lại với Greedy. Công cụ đọc lại file ở đầu mỗi trận. Nếu sửa trong lúc trận chạy, thay đổi chỉ có hiệu lực ở trận tiếp theo.

5. Dữ liệu engine gửi cho bạn

observation[...]Nội dung
valid_movesDanh sách nước hợp lệ; mỗi nước có bốn tọa độ và is_capture (True nếu ăn quân).
boardDanh sách 81 ô. Ô (col, row) nằm ở board[row * 9 + col].
board_2dCùng bàn cờ, truy cập bằng board_2d[row][col].
current_playerBên tới lượt: 1 hoặc 2. Nên đọc trường này thay vì tự cố định trong code.
piece_countsSố quân theo bên và loại. Qua JSON, khóa bên là chuỗi "1", "2".
move_countTổng số nước hai bên đã đi.
game_overTrận đã kết thúc hay chưa.

Ô trống là None. Ô có quân là ví dụ {"player": 1, "type": "ROCK"}. Ba loại: ROCK (Đấm), PAPER (Lá), SCISSORS (Kéo). Đấm thắng Kéo, Kéo thắng Lá, Lá thắng Đấm. configuration hiện là dictionary rỗng {}.

Quân đi một ô theo 8 hướng. P1 thắng khi vào i9 hoặc tiêu diệt hết một loại quân đối phương; P2 hướng tới a1 với điều kiện tương tự. Đủ 200 nước tổng hai bên thì hòa; không hòa sớm vì lặp thế.

Mỗi lượt Python khởi động lại agent. Biến toàn cục không được nhớ qua lượt. Chỉ dùng thư viện chuẩn Python để phù hợp máy chấm. Greedy có một chút ngẫu nhiên, nên chạy lại có thể ra kết quả khác.

6. Xem live, tua và lưu kết quả

Theo dõi trực tiếp đưa bàn cờ tới nước mới nhất. Kéo thanh tua hoặc bấm Trước sẽ xem lịch sử, trong khi engine vẫn chạy tiếp. Bấm Về hiện tại để theo dõi tiếp.

Tạm dừng xem chỉ dừng hình đang phát; Dừng trận mới dừng tính agent. Tốc độ 1,2 giây/nước chỉ áp dụng khi phát lịch sử. Có thể bấm từng nước trong danh sách bên phải hoặc mở toàn màn hình.

Kết thúc hoặc lỗi, bản ghi tự lưu trong app/results/. Nút Tải replay HTML tạo file mở được bằng trình duyệt kể cả khi không có mạng. Nút Tải JSON dành cho phân tích bằng code. Không có mã nguồn agent trong bản ghi tải xuống; log có thể chứa nội dung bạn đã print.

Thoát bằng nút Thoát công cụ hoặc Ctrl+C trong cửa sổ chạy. Đóng tab trình duyệt không dừng engine.

7. Khi xuất hiện lỗi

Đọc khung đỏ từ trên xuống: tên file → dòng → lượt → loại lỗi → giải thích. Đoạn code hiển thị đúng bản đã dùng trong trận, kể cả nếu bạn vừa sửa file. Bấm “Đến thời điểm lỗi” để xem bàn cờ ngay trước lỗi. Mở Chi tiết kỹ thuật để xem traceback hoặc sao chép gửi người hỗ trợ.

LỗiCách xử lý
SyntaxErrorKiểm tra dấu :, dấu ngoặc, dấu nháy; ví dụ if phải kết thúc bằng dấu :.
IndentationError / TabErrorSửa thụt lề, dùng 4 dấu cách mỗi cấp.
NameError / KeyErrorKiểm tra tên biến hoặc tên trường; Python phân biệt chữ hoa và thường.
Không tìm thấy hàm agentGiữ đúng tên agent và hai tham số như mẫu.
InvalidMove / IllegalMoveĐọc nước trả về và lý do; thử chọn trực tiếp từ valid_moves như mẫu.
TimeoutQuá 12 giây một lượt. Kiểm tra while vô hạn hoặc giảm độ sâu tìm kiếm.
OutputLimitQuá 64 KiB stdout/stderr một lượt. Giảm print() trong vòng lặp.
Mất kết nốiGiữ cửa sổ chạy mở. Nếu đã đóng, mở lại run.cmd và dùng địa chỉ mới.

Sửa xong, Ctrl+S rồi Chạy lại. Nếu lỗi ghi “Greedy” hoặc “Công cụ local”, gửi chi tiết cho người cung cấp; công cụ không quy lỗi đó thành agent bạn thua.

Bộ local chạy code bạn tin cậy, không cách ly filesystem hoặc mạng. Luật giống đấu thường nhưng giới hạn CPU/RAM và tốc độ máy không được bảo đảm giống server. Không cần nộp cả thư mục; khi nộp agent, dùng nội dung my_agent.py theo hướng dẫn cuộc thi.
